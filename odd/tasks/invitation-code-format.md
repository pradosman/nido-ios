# Invitation code format

## Objective
Make a caregiver invitation generated by Nido joinable through the iPhone form, including codes already issued by the current server.

## Problem and evidence
Before this fix, the server returned a 22-character Base64URL secret. The iPhone field stripped non-alphanumerics, truncated at 12 characters, inserted separators, and submitted the displayed value. The server hashed the submitted string unchanged, so a generated code could not match. Existing API tests submitted the raw response and missed this cross-boundary failure.
